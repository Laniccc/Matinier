# 常驻字幕的助手侧栏设计

用户已确认采用左侧活动栏＋可折叠助手侧栏，不再从 Room 跳转到助手页面。

## 布局与交互

- 最左侧活动栏提供“直播空间”和“助手”按钮，复用同一个侧栏；中间音频控制与字幕组件保持原位置和挂载身份。
- 默认展示直播空间。点击助手按钮或原“助手工作区”入口就地展开助手；再次点击当前活动按钮可折叠，切换活动项会展开。
- 助手侧栏跟随当前字幕 Session，展示通用插件目录、插件状态、实时视图和可信文档，不包含课程特判。
- 侧栏默认宽度 384px（包含活动栏），支持拖动分隔条及键盘调整，限制合理宽度。窄屏面板覆盖部分内容但不卸载字幕，保留显式关闭入口。
- 历史助手工作区、插件管理及文档下载在新标签页打开；日常查看实时助手不进行路由跳转。

## 生命周期与数据边界

- RoomStudio 继续持有 LiveKit Room、音轨和采集上下文。侧栏按钮仅更新 UI 状态，不调用停止、断连、切换 Room 或切换字幕 Session。
- 直播空间面板和助手面板保持挂载，仅通过 hidden 切换可见性；折叠不清空输入和插件选择，不重复创建助手轮询。
- 只使用一份当前 Session 的助手加载 hook；沿用已验证的请求代数保护、插件级命令错误和文档隔离。
- 退出整个页面时仍执行现有音频清理；本设计不承诺刷新、关闭原标签页后采集继续。
- 此次确认是侧栏实现授权，不替代先前“重启后端并处理历史积压字幕”的单独授权。

## 验收

用真实 React DOM 挂载和模拟 LiveKit 音轨验证：开启采集后打开助手、折叠、切换空间/助手、切换插件、调整宽度，均不调用 stop/unpublish/disconnect，中央字幕节点身份不变；最终真正卸载 RoomStudio 仍清理资源。验证多插件展示/输入隔离和当前 Session 跟随、管理链接不在原标签页跳转。运行全量前端测试、typecheck、production build。

浏览器工具先前受到 URL 安全策略限制，本次不绕过。DOM 回归不等同于真实浏览器视觉、分享音频权限和窗口管理验收；这些限制在交付时明确说明。
